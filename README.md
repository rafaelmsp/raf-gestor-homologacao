# RAF — Ambiente de homologação

Este repositório é público apenas para entregar a interface de **testes**.
O repositório completo, SQL, documentação interna e testes ficam privados.

A página HTML é acessível por qualquer pessoa; o Supabase exige autenticação
e Row Level Security para acessar os dados. Não usar dados processuais reais.
Este ambiente **não** é homologado pelo TJRJ ou por qualquer órgão público.
A futura versão de produção deve proteger também o acesso à interface.
